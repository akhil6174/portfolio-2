# Assets folder

Place your real images here:

- `profile-placeholder.jpg` → replace with your actual profile photo (recommend a square image, at least 600x600px)
- `projects/wifi-sensing.jpg`, `projects/rag-assistant.jpg`, `projects/portfolio.jpg`, `projects/sentiment.jpg` → replace with real project screenshots (recommend 16:10 aspect ratio, at least 1200px wide)

If an image is missing, the site gracefully falls back to a placeholder block so nothing breaks visually.

Also add your real resume PDF at `/public/resume-placeholder.pdf` (or update `resumeUrl` in `src/data/profile.js` to point elsewhere), and an Open Graph cover image at `/public/og-cover.png` (1200x630px recommended) for social sharing previews.
